# 🗡 سنگ کاغذ قیچی — نبرد پهلوانان ایران‌زمین

بازی موبایل «سنگ کاغذ قیچی» با تم باستانی ایرانی، ساخته‌شده برای **اندروید استودیو** (Kotlin + Java).

## 📱 مشخصات

| مورد | مقدار |
|---|---|
| زبان | Kotlin + یک کلاس Java (`PersianUtil`) |
| minSdk / targetSdk | 24 (اندروید ۷) / 34 |
| فونت | لاله‌زار (در `res/font/lalezar.ttf`) |
| رویداد | RTL کامل و فارسی |
| تبلیغات | ادیوری ۴٫۹٫۰ — تبلیغ جایزه‌ای کلاکت |
| خرید درون‌برنامه‌ای | کافه بازار — کلاس‌های کمکی رسمی + AIDL |
| کامپایل | AGP 8.2.2 + Gradle 8.2.1 + JDK 17 |

## ▶️ اجرا در اندروید استودیو

1. **File → Open** و پوشه `SangKaghazGheychi` را باز کنید.
2. صبر کنید Gradle Sync تمام شود (اولین بار چند دقیقه طول می‌کشد).
3. دکمه **Run ▶** را بزنید یا از منوی **Build → Build APK(s)** خروجی بگیرید.
4. فایل APK در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

> اگر Gradle Sync خطا داد: در **Settings → Build Tools → Gradle** گزینه Gradle wrapper را انتخاب کنید و مطمئن شوید JDK 17 تنظیم است.

## 🎮 بخش‌های بازی

### منو
- شروع بازی / فروشگاه / خروج
- **دکمه صدا در بالا سمت چپ**: قطع/وصل افکت‌های بازی (دائمی ذخیره می‌شود)
- باکس سکه و آمار پیروزی و باخت (با انیمیشن معلق)
- **آمار بر اساس نتیجه کل نبرد ثبت می‌شود، نه هر راند:**
  - بردِ راندها > باختِ راندها ← یک برد به منو اضافه می‌شود
  - باختِ راندها > بردِ راندها ← یک باخت اضافه می‌شود
  - مساوی بودن ← هیچ چیزی اضافه نمی‌شود
  - (نمونه: ۳ برد و ۱ باخت در یک نبرد ← فقط +۱ برد | ۲ برد و ۳ باخت ← فقط +۱ باخت)
  - ⚠️ نسخه‌های قدیمی آمار اشتباه انباشته کرده بودند؛ با اولین اجرای نسخه ۱٫۳ یک‌بار صفر می‌شود.

### نبرد
- ۵ راند؛ لوزی هر راند: **طلایی = برد، قرمز = باخت، آبی = مساوی**
- انتخاب دست پایین صفحه → دست‌های بزرگ به سمت مرکز حرکت می‌کنند، دست حریف (هوش مصنوعی) بعد از چرخش بین حالت‌ها، دستش را نشان می‌دهد.
- حریف‌ها با نام‌های قدیمی: سردار گودرز، پهلوان پنبه، آرش کمانگیر، رستم دستان، سهراب، کاوه آهنگر
- **حساب‌وکتاب مخفیانه:** هر برد راند +۱۰ سکه، هر باخت -۵ سکه، مساوی ۰ — تا پایان نبرد نمایش داده نمی‌شود و فقط نتیجه نهایی دیده می‌شود.

### فروشگاه (۳ بخش)
- **دست‌ها:** ۲۰ پوست — پهلوانی، خطاطی گل، خطاطی نستعلیق، دست حنا، پرچم ایران، تیر و کمان، سرباز هخامنشی، کوه دماوند، مفرغی، ماه و ستاره، طلایی، خاتم‌کاری، کاشی اصفهان، انار سرخ، فیروزه‌کاری، خورشید، خنجر زرین، پر سیمرغ، درفش کاویانی و شاهنشاهی (با نشان «در بازار سیاه»).
- **پس‌زمینه‌ها:** ۱۰ پس‌زمینه — تخت جمشید (پیش‌فرض)، برج آزادی، کویر، بادگیرهای یزد، حافظیه شیراز، پارسه در شب، پل خواجو، چغازنبیل، نقش جهان و **آرامگاه کوروش (گران‌ترین، ۸۰۰ سکه)** — بعد از خرید در **همه صفحات** اعمال می‌شود.
- **بازار سیاه:** خرید واقعی کافه بازار + باکس موجودی سکه در نوار بالا.
  - اگر کافه بازار نصب نباشد پیام «کافه بازار را نصب کن» نمایش داده می‌شود؛ قیمت بسته‌ها بعد از اتصال، از پنل کافه بازار تازه می‌شود.
- دکمه **کلاکت جایزه** (پایین-چپ): تبلیغ جایزه‌ای ادیوری — تماشای کامل = ۱۵ سکه.
- کلید اپلیکیشن و کلید جایگاه ادیوری در `ads/AdReward.kt`؛ مقداردهی SDK در `SangApp`؛ پیش‌بارگذاری هنگام باز شدن فروشگاه.

## 🛒 خرید درون‌برنامه‌ای کافه بازار (وصل شده)

طبق مستندات رسمی `developers.cafebazaar.ir/fa/guidelines/in-app-billing` (روش جاوا) پیاده شده است:

- کتابخانه: کلاس‌های کمکی رسمی بازار (پوشه `billing/util/` شامل `IabHelper` و یارانش) + `IInAppBillingService.aidl` در `app/src/main/aidl/com/android/vending/billing/`
- کلید عمومی بازی در `app/build.gradle` → `buildConfigField IAB_PUBLIC_KEY`
- منیفست: پرمیشن `com.farsitel.bazaar.permission.PAY_THROUGH_BAZAAR` + تگ `queries` برای دیدن بازار در اندروید ۱۱ به بالا + گیرنده پشتیبان `IABReceiver` (حالت broadcast)
- منطق پرداخت: `billing/BazaarIap.kt` — اتصال (`setup`)، به‌روزرسانی خریدها (`queryInventory`)، خرید (`purchase`)، نتیجه خرید (`handleActivityResult` در `MainActivity`)، تحویل و مصرف (`consume`)
- شناسه محصولات (باید دقیقاً با پنل کافه بازار یکی باشد):

| بسته | شناسه محصول | جایزه |
|---|---|---|
| کیسه | `Coin600` | ۶۰۰ سکه |
| صندوق | `coin1500` | ۱٫۵۰۰ سکه |
| گنج | `coin2200` | ۲٫۲۰۰ سکه |
| شاهنشاهی | `shah` | ۵٫۰۰۰ سکه + دست شاهنشاهی |

- **امنیت تحویل:** توکن هر خرید در `GamePrefs` ثبت می‌شود؛ اگر خریدی بین پرداخت و تحویل قطع شود، در باز شدن بعدی فروشگاه از طریق `queryInventory` فقط یک‌بار تحویل و مصرف می‌شود (بدون دوباره‌پرداختی).
- همه بسته‌ها «مصرف‌شدنی» هستند تا خرید دوباره ممکن باشد؛ بعد از تحویل موفق مصرف می‌شوند.

## 🔧 سفارشی‌سازی

### جایگزینی گرافیک با طرح‌های خودتان
همه تصاویر در `app/src/main/res/drawable/` هستند. کافی است هم‌نام آن‌ها را جایگزین کنید:

| الگوی نام | توضیح |
|---|---|
| `hand_<پوست>_<حالت>.png` | ۲۰ پوست × fist / scissors / palm (مثل `hand_gol_fist.png`) |
| `bg_<نام>.png` | پس‌زمینه‌ها + `bg_<نام>_thumb.png` برای کارت فروشگاه |
| `coin.png` | آیکون سکه |

نام پوست‌ها در `data/Skins.kt` و نام پس‌زمینه‌ها در `data/Backgrounds.kt` تعریف شده‌اند.

### تغییر قیمت‌ها و اسم‌ها
- قیمت‌ها: `Skins.kt` و `Backgrounds.kt`
- اسامی حریف‌ها: `data/Opponents.kt`
- قوانین سکه: ثابت‌های `WIN_COIN` و `LOSE_COIN` در `game/RpsGame.kt`
- متن‌ها: `res/values/strings.xml`

### خرید کافه بازار
- شناسه محصولات و مقادیر سکه: `billing/BazaarIap.kt` (`coinsFor`)
- کلید عمومی: `app/build.gradle` → `IAB_PUBLIC_KEY`
- شناسه‌ها در پنل پرداخت بازار (سربرگ «پرداخت درون‌برنامه‌ای») باید دقیقاً `Coin600`، `coin1500`، `coin2200` و `shah` باشند.

```
│   ├── GamePrefs.kt         → ذخیره سکه، آمار، خریدها، توکن‌های تحویل‌شده (SharedPreferences)

│   ├── Backgrounds.kt       → تعریف ۱۰ پس‌زمینه

├── audio/SoundManager.kt    → افکت‌های صوتی (SoundPool)
├── util/
│   ├── PersianUtil.java     → ارقام فارسی (کلاس Java!)

```
